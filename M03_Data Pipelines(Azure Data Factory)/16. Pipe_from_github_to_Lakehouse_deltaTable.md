# Pipe_from_github_to_Lakehouse_deltaTable
---

## Copy a CSV file from GitHub into a Lakehouse Delta table

This chapter demonstrates a Copy data pipeline that reads `Labdata/emp.csv` from the `rritec/Microsoft-Fabric` GitHub repository and appends its rows to the `github_emp` table in a Lakehouse.

> The connection IDs and workspace/Lakehouse IDs in the example JSON are specific to one Fabric environment. Use the corresponding IDs and connection in your workspace.

---

## 1. Prepare the source CSV

The source file used in this example is:

- Repository: `rritec/Microsoft-Fabric`
- Branch: `main`
- File: `Labdata/emp.csv`
- GitHub relative URL: `rritec/Microsoft-Fabric/refs/heads/main/Labdata/emp.csv`

Ensure the CSV has a header row and is accessible to the HTTP connection you will use. For a private repository, configure access in the connection rather than embedding credentials in the pipeline JSON.

---

## 2. Create the pipeline

1. Open [Microsoft Fabric](https://app.fabric.microsoft.com) and go to your target workspace.
2. Select **New** → **Data pipeline**.
3. Name the pipeline `Pipe_from_github_to_Lakehouse_deltaTable`.
4. Add a **Copy data** activity.

---

## 3. Configure the source

1. Select the Copy activity and open **Source**.
2. Choose **DelimitedText** as the source format and select or create an HTTP connection.
3. Configure the connection for the raw GitHub content host, `https://raw.githubusercontent.com/`.
4. Set the relative URL to:

   ```text
   rritec/Microsoft-Fabric/refs/heads/main/Labdata/emp.csv
   ```
5. Set the request method to **GET**.
6. Configure the delimited text format:
   - Column delimiter: comma (`, `)
   - First row as header: enabled
   - Quote character: double quote (`"`)
   - Escape character: backslash (`\`)

---

## 4. Configure the Lakehouse sink

1. Open **Sink** and choose **Lakehouse**.
2. Select the Lakehouse connection and the `Tables` root folder.
3. Set the destination table to `github_emp`.
4. Set write behavior to **Append**.
5. Keep **Apply V-Order** off and **Enable timestamp without time zone** off, as shown in the pipeline JSON.

---

## 5. Configure mapping, publish, and run

1. In **Mapping**, import the source schema if needed.
2. Enable type conversion and allow data truncation; leave `treatBooleanAsNumber` disabled.
3. Confirm staging is disabled.
4. Save and publish the pipeline.
5. Run it, then use **Monitor** to check that the Copy activity succeeds.
6. Verify that rows from `emp.csv` were appended to the `github_emp` Lakehouse table.

---
