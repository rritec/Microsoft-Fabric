# Pipeline: Archive an Excel Workbook in a Lakehouse

## Purpose

This Microsoft Fabric Data Pipeline copies an Excel workbook stored in the `lh_bronze` Lakehouse to an `archive` folder in the same Lakehouse. The copy uses binary mode, so it preserves the workbook as-is rather than reading or transforming its worksheets. The destination filename includes a timestamp in Eastern Standard Time to distinguish archived copies.

> **Important:** The source read settings enable recursive file reading and `deleteFilesAfterCompletion`. After a successful copy, the source file(s) read by this activity are deleted. Confirm this is intended before running the pipeline.

---

## Key Activities

### 📌 Activity: Copy data2

- **Type**: Copy (binary)
- **Source**: Lakehouse `lh_bronze`, file `Load_multiple_sheets_of_excel.xlsx`
- **Source settings**: Recursive read enabled; source files are deleted after successful completion
- **Sink**: The same Lakehouse, under `Files/archive`
- **Output filename**: `load_multiple_sheets_of_excel_` plus the current Eastern Standard Time timestamp, followed by `.xlsx`
- **Data transformation**: None; binary copy preserves the workbook contents

---

## Navigation Steps to Create This Pipeline

1. Go to **Data Factory** in your Microsoft Fabric workspace.
2. Create a pipeline named `Load_Multiple_Excel_Sheets_To_Lakehouse`.
3. Add a **Copy Data** activity named `Copy data2`.
4. Configure the **Source** as a Lakehouse binary dataset:
   - Select the `lh_bronze` Lakehouse.
   - Set the file name to `Load_multiple_sheets_of_excel.xlsx`.
   - Enable recursive reading if needed.
   - Keep `deleteFilesAfterCompletion` enabled only if the source workbook should be removed after a successful copy.
5. Configure the **Sink** as a binary dataset in the same Lakehouse:
   - Set the folder path to `archive`.
   - Use this expression for the output file name:

   ```text
   @concat(
       'load_multiple_sheets_of_excel_',
       formatDateTime(
           convertTimeZone(
               utcNow(),
               'UTC',
               'Eastern Standard Time'
           ),
           'yyyy-MM-ddTHH:mm:ss.fffffff'
       ),
       '.xlsx'
   )
   ```

6. Publish and trigger the pipeline. Verify the timestamped workbook appears in `Files/archive` and, if configured, the source file has been removed.
