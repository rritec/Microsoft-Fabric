## Step 1: Create SQL Database and sample data

- Go to the workspace where you want to create your database.
- Click **+ New item**, then choose **SQL Database**.
- Name your database (for example, `EmployeeDB`) and click **Create**.

### SQL script: Create tables and insert sample data

```sql
CREATE TABLE dept (
    dept_id INT PRIMARY KEY,
    dept_name VARCHAR(50)
);

CREATE TABLE emp (
    emp_id INT PRIMARY KEY,
    emp_name VARCHAR(100),
    hire_date DATE,
    salary DECIMAL(10, 2),
    dept_id INT,
    FOREIGN KEY (dept_id) REFERENCES dept(dept_id)
);

INSERT INTO dept (dept_id, dept_name) VALUES
(10, 'Sales'),
(20, 'Engineering'),
(30, 'HR');

INSERT INTO emp (emp_id, emp_name, hire_date, salary, dept_id) VALUES
(101, 'Alice Johnson', '2022-05-15', 72000.00, 20),
(102, 'Bob Smith', '2021-11-03', 68000.00, 10),
(103, 'Clara Martinez', '2023-01-10', 62000.00, 30),
(104, 'David Kim', '2020-08-20', 75000.00, 20);
```

## Step 2: Create and configure the data pipeline

1. Open [Microsoft Fabric](https://app.fabric.microsoft.com) and go to your target workspace.
2. Select **New** → **Data pipeline**.
3. Name the pipeline `Pipe_from_SqlDatabase_to_Lakehouse_deltaTable`.
4. Add a **Copy data** activity and configure its source and sink as described below.

### Mapping and type conversion

Enable type conversion and allow data truncation. Leave `treatBooleanAsNumber` disabled.

### Publish and run

1. Click **save** 
2. Click **Run**
3. Confirm that the Copy activity succeeds and the `emp` table is populated in the `lh_bronze` Lakehouse.
